# Технічне завдання
## Система аналізу біометричних показників стресу

**Версія**: 1.0
**Дата**: 2025-11-24

---

## 1. Загальні відомості

### 1.1. Найменування системи
Веб-система аналізу біометричних показників стресу (Biometric Stress Analysis System)

### 1.2. Призначення системи
Система призначена для збору, зберігання, аналізу біометричних даних користувачів з метою визначення рівня стресу та надання персоналізованих рекомендацій для його зниження.

### 1.3. Цільова аудиторія
- Звичайні користувачі, які хочуть відстежувати свій рівень стресу
- Медичні працівники для моніторингу пацієнтів
- Адміністратори системи для управління даними

---

## 2. Функціональні вимоги

### 2.1. Модуль автентифікації та авторизації

#### 2.1.1. Реєстрація користувачів
- Система повинна дозволяти новим користувачам реєструватися
- Обов'язкові поля: ім'я, прізвище, email, пароль, username
- Додаткові поля: дата народження, стать, телефон
- Перевірка унікальності email та username
- Валідація формату email
- Мінімальна довжина пароля: 6 символів
- Автоматичне шифрування пароля (BCrypt)

#### 2.1.2. Автентифікація
- Вхід користувачів за допомогою email/username та пароля
- Генерація JWT токенів при успішній автентифікації
- Термін дії токена: 24 години
- Автоматичне оновлення токена при активності користувача

#### 2.1.3. Авторизація
- Розмежування прав доступу за ролями: USER, DOCTOR, ADMIN
- USER - доступ до власних даних
- DOCTOR - доступ до даних пацієнтів
- ADMIN - повний доступ до системи

### 2.2. Модуль управління біометричними даними

#### 2.2.1. Введення біометричних даних
Система повинна приймати наступні показники:

**Обов'язкові показники:**
- Пульс (частота серцевих скорочень, уд/хв): 40-200
- Систолічний тиск (мм рт. ст.): 80-200
- Діастолічний тиск (мм рт. ст.): 40-130
- Температура тіла (°C): 35.0-42.0
- Час вимірювання

**Додаткові показники:**
- Рівень кортизолу (нмоль/л): 0-1000
- Кількість годин сну: 0-24
- Якість сну (POOR, FAIR, GOOD, EXCELLENT)
- Частота дихання (вдихів/хв): 8-40
- Сатурація кисню (%): 70-100
- Рівень активності (кроків або хвилин)
- Нотатки користувача (до 500 символів)

#### 2.2.2. Валідація даних
- Перевірка діапазонів значень
- Автоматичне встановлення часу вимірювання
- Попередження при аномальних значеннях

#### 2.2.3. Збереження та історія
- Збереження всіх вимірювань у базі даних
- Прив'язка до конкретного користувача
- Можливість перегляду історії вимірювань
- Сортування за датою (нові спочатку)
- Можливість видалення власних записів

### 2.3. Модуль аналізу стресу

#### 2.3.1. Алгоритм розрахунку
Система використовує комплексний підхід для визначення рівня стресу:

**Компоненти оцінки:**
1. **Серцево-судинна оцінка (30%)**
   - Пульс
   - Систолічний та діастолічний тиск

2. **Термальна оцінка (15%)**
   - Температура тіла

3. **Біохімічна оцінка (25%)**
   - Рівень кортизолу

4. **Оцінка сну (20%)**
   - Кількість годин сну
   - Якість сну

5. **Респіраторна оцінка (10%)**
   - Частота дихання
   - Сатурація кисню

**Загальна оцінка стресу:**
- Шкала: 0-100 балів
- 0-24: Низький рівень стресу
- 25-49: Помірний рівень стресу
- 50-74: Високий рівень стресу
- 75-100: Критичний рівень стресу

#### 2.3.2. Результати аналізу
- Загальний рівень стресу
- Оцінки за кожним компонентом
- Текстовий опис стану
- Дата та час аналізу
- Рекомендації

### 2.4. Модуль рекомендацій

#### 2.4.1. Генерація рекомендацій
На основі результатів аналізу система генерує рекомендації в категоріях:

1. **Фізична активність**
   - Вправи для зниження стресу
   - Рекомендована інтенсівність

2. **Харчування**
   - Корисні продукти
   - Що уникати

3. **Сон**
   - Рекомендації щодо режиму сну
   - Поради для покращення якості сну

4. **Релаксація**
   - Техніки розслаблення
   - Медитація, дихальні вправи

5. **Медична консультація**
   - Коли звернутися до лікаря
   - Що обговорити з лікарем

6. **Стиль життя**
   - Загальні поради
   - Зміни в повсякденному житті

#### 2.4.2. Пріоритизація
- LOW: загальні рекомендації
- MEDIUM: важливі поради
- HIGH: пріоритетні дії
- URGENT: негайні дії (при критичному рівні стресу)

### 2.5. Модуль користувача

#### 2.5.1. Профіль користувача
- Перегляд та редагування особистих даних
- Зміна пароля
- Перегляд статистики
- Налаштування сповіщень

#### 2.5.2. Панель управління (Dashboard)
- Останні біометричні показники
- Останній аналіз стресу
- Графік показників за період
- Активні рекомендації
- Швидке додавання нових даних

#### 2.5.3. Історія
- Перегляд усіх вимірювань
- Фільтрація за датою
- Перегляд детальної інформації
- Експорт даних (майбутня функція)

### 2.6. Модуль адміністратора (Admin Panel)

#### 2.6.1. Управління користувачами
- Перегляд списку всіх користувачів системи
- Фільтрація користувачів за роллю (USER, DOCTOR, ADMIN)
- Перегляд статистики користувачів:
  - Загальна кількість користувачів
  - Кількість активних користувачів
  - Кількість адміністраторів
  - Кількість лікарів

#### 2.6.2. Операції над користувачами
- Блокування/розблокування користувачів (toggle active status)
- Зміна пароля будь-якому користувачу
- Видалення користувачів з системи
- Обмеження: адмін не може заблокувати або видалити самого себе

#### 2.6.3. Таблиця користувачів
Відображення інформації:
- ID користувача
- Username
- Email
- Ім'я та прізвище
- Роль (USER/DOCTOR/ADMIN)
- Статус (Активний/Заблокований)
- Дії (Змінити пароль, Блокувати, Видалити)

#### 2.6.4. Модальне вікно зміни пароля
- Введення нового пароля
- Підтвердження нового пароля
- Валідація співпадіння паролів
- Мінімальна довжина: 6 символів

### 2.7. Модуль лікаря (Doctor Panel)

#### 2.7.1. Перегляд пацієнтів
- Список всіх активних пацієнтів (користувачів з роллю USER)
- Відображення інформації про пацієнта:
  - Ім'я та прізвище
  - Username
  - Email
  - Статус активності

#### 2.7.2. Статистика пацієнтів
Загальна статистика:
- Всього пацієнтів
- Активні пацієнти

Статистика обраного пацієнта:
- Середній рівень стресу
- Загальна кількість аналізів
- Візуальний індикатор рівня стресу з кольоровим кодуванням:
  - 0-24: Зелений (Низький)
  - 25-49: Жовтий (Помірний)
  - 50-74: Помаранжевий (Високий)
  - 75-100: Червоний (Дуже високий)

#### 2.7.3. Детальна інформація про пацієнта
- Особисті дані пацієнта
- Середній рівень стресу за весь час
- Загальна кількість проведених аналізів
- Кнопка переходу до детальної історії пацієнта (майбутня функція)

#### 2.7.4. Інтерактивний інтерфейс
- Вибір пацієнта зі списку
- Автоматичне завантаження статистики при виборі
- Виділення обраного пацієнта
- Індикатори завантаження даних

### 3.5. Зручність використання (Usability)

## 4. Технічні вимоги

### 4.1. Backend
- **Мова**: Java 17
- **Фреймворк**: Spring Boot 3.2.0
- **База даних**: PostgreSQL 16
- **Безпека**: Spring Security + JWT
- **API**: RESTful
- **Документація**: Swagger/OpenAPI
- **Система збірки**: Maven

### 4.2. Frontend
- **Бібліотека**: React 19
- **Мова**: TypeScript
- **Збірка**: Vite
- **HTTP клієнт**: Axios
- **Візуалізація**: Recharts
- **Стилі**: CSS Modules / Inline styles

### 4.3. База даних
- **СКБД**: PostgreSQL 16
- **ORM**: Hibernate (через Spring Data JPA)
- **Міграції**: Автоматичні (Hibernate DDL)

### 4.4. DevOps
- **Контейнеризація**: Docker
- **Оркестрація**: Docker Compose
- **Веб-сервер**: Nginx (для frontend)
- **CI/CD**: Майбутня функція
