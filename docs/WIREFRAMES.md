## 1. Загальні принципи дизайну

### 1.1. Колірна схема
- **Primary**: #3B82F6 (синій) - кнопки, акценти
- **Success**: #10B981 (зелений) - успішні операції, низький стрес
- **Warning**: #F59E0B (помаранчевий) - попередження, помірний стрес
- **Danger**: #EF4444 (червоний) - помилки, високий/критичний стрес
- **Background**: #F9FAFB (світло-сірий)
- **Text**: #1F2937 (темно-сірий)
- **Border**: #E5E7EB (світло-сірий)

### 1.2. Типографія
- **Заголовки**: 24-32px, напівжирний
- **Підзаголовки**: 18-20px, напівжирний
- **Основний текст**: 14-16px, звичайний
- **Малий текст**: 12-14px, звичайний
- **Шрифт**: система (SF Pro, Roboto, Arial)

### 1.3. Компоненти
- **Кнопки**: заокруглені кути (8px), тіні
- **Картки**: білий фон, тонка тінь, заокруглені кути
- **Форми**: чіткі мітки, валідація в реальному часі
- **Іконки**: Lucide React (консистентний стиль)

### 2.2. Елементи

**Компоненти**:
1. Логотип + назва системи (центрований)
2. Заголовок "Вхід в систему"
3. Поле "Email або Username" з іконкою

5. Чекбокс "Запам'ятати мене"
6. Кнопка "Увійти" (primary, повна ширина)
7. Посилання "Забули пароль?"
8. Розділювач
9. Посилання на реєстрацію

**Валідація**:
- Перевірка формату email (якщо введено email)
- Мінімальна довжина пароля
- Відображення помилок під полями

**Стани**:
- Default
- Focus (синя рамка)
- Error (червона рамка + текст помилки)
- Loading (кнопка з спінером)
- Success (перехід на Dashboard)

## 10. Користувацький досвід (UX)

### 10.1. Принципи

1. **Простота**: мінімум кліків для основних дій
2. **Зрозумілість**: іконки + текст, зрозумілі мітки
3. **Зворотний зв'язок**: миттєві підтвердження дій
4. **Доступність**: WCAG 2.1 AA compliance
5. **Послідовність**: консистентний дизайн

### 10.2. Мікроінтеракції

- **Hover effects**: легке піднесення карток, зміна кольору кнопок
- **Loading states**: скелетони та спінери
- **Success animations**: галочки, плавна поява
- **Error states**: тремтіння полів, червоні рамки
- **Transitions**: плавні переходи між станами

### 10.3. Feedback

**Успішні операції**:
- Toast notification (зелений, 3 сек)
- Іконка галочки
- Успішний звук (опціонально)

**Помилки**:
- Toast notification (червоний, 5 сек)
- Іконка помилки
- Детальне повідомлення

**Завантаження**:
- Скелетони для контенту
- Спінери для кнопок
- Progress bars для довгих операцій

## 11. Accessibility (A11y)

### 11.1. Вимоги

- **Keyboard navigation**: всі елементи доступні з клавіатури
- **Screen readers**: ARIA labels та alt текст
- **Контраст**: мінімум 4.5:1 для тексту
- **Focus indicators**: чіткі рамки навколо активних елементів
- **Семантичний HTML**: правильні теги

### 11.2. ARIA атрибути

```html
<button aria-label="Додати біометричні дані">➕</button>
<div role="alert" aria-live="polite">Дані збережено</div>
<input aria-required="true" aria-invalid="false" />
```
